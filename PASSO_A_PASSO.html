Dotfiles: passo a passo

Do que fazer agora neste computador até instalar tudo num computador novo. Marque cada passo ao concluir; o progresso fica salvo neste navegador.

1. Instalar neste computador

Compila e ativa tudo o que foi feito hoje.

Rodar o instalador

cd ~/.source && ./install.sh
  • Instala os pacotes que faltam com o pacman e pede a sua senha.
  • Compila e instala o dwm, o dmenu, o st, o slock e o dwmblocks.
  • Troca o ~/Scripts, o ~/.xinitrc, o ~/.Xresources, o dunst e o zathura por links para o repositório. Os arquivos atuais viram .bak-<data>.
Se algum make der erro, o script para ali. Copie a saída e me mande: é a primeira compilação completa, então um erro é possível.

Testar o slock com uma saída garantida

Antes de confiar no bloqueio novo, abra um terminal em outro TTY com Ctrl+Alt+F2, entre com seu usuário e volte ao X com Ctrl+Alt+F1. Então rode:

slock

Digite a senha e Enter para desbloquear. Se travar, vá ao TTY 2 e rode:

pkill slock

Sair e entrar de novo no X

Carrega o .xinitrc novo (PATH dos scripts, xss-lock, cores). Use Super+Shift+Q → Sair do dwm e depois:

startx
A tecla principal agora é Super (a tecla Windows), não mais Alt. Aperte Super+F1 para ver todos os atalhos.

Conferir o config.h antigo do slock

Não consegui ler esse arquivo e por isso o renomeei. Se o comando abaixo não mostrar nada, os dois são iguais e você pode apagar o antigo.

diff ~/.source/slock/config.h.antigo ~/.source/slock/config.def.h

2. Publicar no GitHub

Para baixar tudo em outro computador. Usa o gh, que já está configurado na sua máquina.

Criar os repositórios do st, slock e dwmblocks

Hoje eles só existem na sua máquina. O dwm e o dmenu já têm repositório (my-dwm, my-dmenu).

cd ~/.source
for r in st slock dwmblocks; do
  gh repo create lucaslibanio/my-$r --public && git -C $r push -u origin HEAD
done

Troque --public por --private se preferir.

Enviar o dwm e o dmenu

git -C ~/.source/my-dwm push && git -C ~/.source/dmenu push

Criar e enviar o repositório dotfiles

cd ~/.source && gh repo create lucaslibanio/dotfiles --public --source=. --remote=origin --push

3. Num computador novo

Com o Arch instalado, conectado à internet e com o git.

Baixar e instalar

git clone --recursive https://github.com/lucaslibanio/dotfiles.git ~/.source
cd ~/.source && ./install.sh
  • O clone precisa ir para ~/.source, porque o dwmblocks procura os scripts lá.
  • Se os repositórios forem privados, rode gh auth login antes.
  • Para instalar também os opcionais (yt-dlp, scrcpy, wacom, tlp): ./install.sh --extras.

Entrar no X

startx

Se o instalador avisou que o locale pt_BR.UTF-8 não existe, descomente a linha dele em /etc/locale.gen e rode sudo locale-gen. Sem isso, a data aparece em inglês.

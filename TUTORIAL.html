dmenu, st e slock revisados

Como instalar, o que mudou e como usar cada um. Complementa a página do dwm (~/.source/my-dwm/MUDANCAS.html), que também foi atualizada com os atalhos novos.

1. Instalar

  1. Instale as dependências novas: 
    sudo pacman -S --needed harfbuzz imlib2 xclip libnotify playerctl \
  noto-fonts-emoji ttf-nerd-fonts-symbols ttf-nerd-fonts-symbols-mono
    O harfbuzz é para as ligaduras do st, o imlib2 para o fundo desfocado do slock e o xclip para copiar emojis e links.
  2. Compile e instale os quatro programas: 
    for p in dmenu st slock my-dwm; do
  (cd ~/.source/$p && sudo make clean install) || break
done
  3. Reinicie o dwm com Super+Ctrl+Shift+Q. Os terminais já abertos continuam com o st antigo; os novos usam o st novo.
Teste o slock antes de confiar nele. O código passou na checagem de sintaxe, mas não foi possível compilar e rodar aqui. Rode slock com outro terminal aberto em outro TTY (Ctrl+Alt+F2). Se algo der errado, dá para encerrar de lá com pkill slock.
Se o make der erro: me mande a saída. Se quiser voltar atrás, cada repositório tem as mudanças em commits separados (seção 5), e git revert <commit> desfaz um deles.

2. dmenu

Busca aproximada

Não precisa digitar o nome inteiro, nem em sequência: as letras só precisam aparecer na ordem. As letras que bateram ficam em dourado, e os resultados mais próximos vêm primeiro.

lbwflibrewolflibreoffice-writer-fresh

O dmenu_run (Super+P) agora tem histórico: os programas que você mais abre aparecem primeiro. O histórico fica em ~/.cache/dmenu_run_history.

São cerca de 4.000 emojis (nomes em inglês) e símbolos como → ° € ≠ (nomes em português). O escolhido vai para a área de transferência; cole com Ctrl+V.

As cores seguem as do dwm e também podem vir do ~/.Xresources, com as chaves dmenu.background, dmenu.foreground, dmenu.selbackground e dmenu.selforeground. Essa leitura estava quebrada antes: a função existia, mas nunca era chamada.

Outras mudanças

Sublinhado ondulado (undercurl)

O neovim marca erros com um sublinhado ondulado. Não precisa configurar nada, mas o terminfo novo só é instalado pelo make install.

Linhas de caixa (boxdraw)

As molduras do htop, do tmux e do tree são desenhadas pelo próprio st, sem falhas entre os caracteres.

Ligaduras

Ativas, mas a Ubuntu Mono não tem ligaduras. Para ver -> virar →, troque a fonte em config.h para JetBrains Mono.

Texto centralizado (vertcenter)

Se você aumentar chscale (espaço entre linhas), o texto fica no meio da linha, e não grudado no topo.

Recarregar cores

Depois de mudar o ~/.Xresources, rode xrdb ~/.Xresources && pkill -USR1 st e todos os terminais abertos atualizam.

Menu de aplicativos

O st.desktop é instalado junto, e o st passa a aparecer como terminal para o xdg-open e os gerenciadores de arquivos.

4. slock

A tela de bloqueio foi redesenhada. Clique nos estados abaixo para ver o que cada um mostra:

19:42
terça-feira, 17 de novembro
RECEBA GRAÇAS A DEUS
O queComo funciona
FundoA própria tela, desfocada e escurecida. Para pixelado, use pixelsize = 12; para cor sólida, blurradius = 0.NOVO
Relógio, data e mensagemCentralizados em cada monitor, data em português e acentos funcionando. Antes, a mensagem saía "GRACAS" e o relógio caía entre os monitores.MUDOU
Barra abaixo da dataCinza: digitando · vermelha: senha incorreta · dourada: Caps Lock ligado.NOVO
Cancelar rápidoMexer o mouse ou apertar uma tecla nos 3 primeiros segundos desbloqueia sem senha. Isso não vale depois de suspender o computador.NOVO
Tela apagaO monitor desliga depois de 60 s bloqueado. A configuração anterior volta ao desbloquear.NOVO
Teclas de mídiaVolume, mudo, microfone, brilho e play/pause funcionam com a tela bloqueada, e a barra do dwm atualiza.NOVO
Mensagem temporáriaslock -m "Volto em 10 min"
Foto após senha erradaRemovida, como você pediu. O slock não roda mais nenhum comando depois de senhas erradas.REMOVIDO

Configuração (~/.source/slock/config.h)

static const int blurradius   = 12;   /* desfoque do fundo; 0 = cor sólida   */
static const int pixelsize    = 0;    /* 12 = pixelado                        */
static const double dim       = 0.4;  /* quanto escurecer o fundo (0 a 1)     */
static const unsigned int monitortime = 60;  /* segundos até apagar a tela  */
static const int timetocancel = 3;    /* janela do cancelar rápido; 0 desliga */
static const char *message    = "RECEBA GRAÇAS A DEUS";
static const char *fontfamily = "Ubuntu Mono";

As cores também podem vir do ~/.Xresources: slock.color0 (bloqueado), slock.color4 (digitando), slock.color1 (erro), slock.color3 (Caps Lock) e slock.foreground (texto).

Por que as teclas de mídia funcionam: por segurança, o slock roda como o usuário nobody enquanto a tela está bloqueada, e por isso ele não conseguiria mexer no seu áudio. Antes de trocar de usuário, ele cria um processo auxiliar com o seu usuário, que só sabe rodar os comandos da lista mediakeys do config.h.
Antes do primeiro make: não consegui ler o seu config.h antigo do slock, então ele foi renomeado para config.h.antigo. Se você tinha algo diferente nele, compare com diff config.h.antigo config.h.
